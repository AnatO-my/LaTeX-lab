# Roadmap

## Near Term

- Verify beta install-from-source on Windows, macOS, and Linux.
- Complete manual VS Code Extension Host QA.
- Expand beginner-friendly examples and docs.
- Add good-first-issue candidates from parser, docs, and tests.

## Middle Term

- Add local provider support.
- Add richer explanation steps for factor, expand, integrate, and systems.
- Add LaTeX input adapter research and parser spike.
- Add more advanced math domains with focused test coverage.

## Long Term

- Add statistics, matrices, numeric solving, and units.
- Add document and notebook workflows.
- Support external contributors with clear beginner issues.
- Prepare a beta release.

## Open Questions

- Which local model runtime should be the first officially supported provider?
- Should the CLI use JSON-RPC for editor integration or remain subprocess-only longer?
- Which math domains should be prioritized after algebra and calculus?
- How much step verification can be deterministic in the early versions?
- Which beta workflows should be supported before calling the project installable by non-maintainers?
